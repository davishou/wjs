# 銷售分析

用來分析「總表」Excel 的進貨與退貨資料。電腦和手機都能用，不需要安裝伺服器。

## 功能

- **總覽**：基準月與今年累計的銷貨、毛利率、退貨率，每月趨勢圖，提醒漸漸沒來的客戶和滯銷商品。
- **樞紐分析**：可依年、年月、月份、區域、業務員、客戶、類別、商品代號、簡化代碼、顏色、單位、單號分組，並橫向展開。進貨和退貨可以一起比較（淨銷售額、退貨率），可以篩選，也可以切換「彙總／明細」，結果能匯出 CSV。
- **客戶交易**：第一筆交易、最近交易、交易至今月數、靜止月數、購買頻率（天），算法和 Excel 的 AK～AP 欄相同。
- **商品銷售與滯銷**：可切換商品代號或簡化代碼，顯示第一筆售出、最近售出、已賣月數、滯銷／停售月數，算法和 Excel 的 AT～AX、BM～BR 欄相同。
- **儀表板**：重點提醒（自動找出要注意的地方）、淨銷售／毛利／毛利率／退貨率／單數／客戶數和去年同期比較，客戶、商品（款號）、業務員、區域、大類、類別的排名與毛利貢獻（金額和 %），區域、大類、類別佔比，毛利率與退貨率每年、每季、每月比較，損益兩平（填每月固定費用），應收帳款天數（填應收帳款餘額），新客戶、可能流失、衰退的大客戶，撐起 80% 業績的款號、新品、退貨率最高的款號，以及缺少哪些資料。每個數字都有「這代表什麼、該注意什麼」。
- **示範資料**：「資料與設定」→「看示範資料」，用一組假的公司資料看每一頁的樣子。只放在畫面上，不會存檔，也不會影響你的資料；看完按「回到我的資料」。
- **圖表報告**：給管理人員看的比較圖，一年一份並和去年同期比較：重點數字、每月淨營收、TOP 10 客戶、TOP 15 商品、區域佔比、各品項佔比、男女童百貨比例、商品毛利貢獻排行。每張圖有一句重點和數字表。可以用「簡報模式」開會投影（一張圖一頁，方向鍵換頁），或「列印／存成 PDF」寄給主管（A4 橫向，一張圖一頁）。
- **商品類別代碼表**：在「資料與設定」匯入代碼表（商品類別(代碼)、商品類別、大類），就會顯示類別名稱和男／女／童／配件大類。只加密存在你的裝置，資料包會一起帶到手機，不會放進 repo。
- **尺寸與顏色**：商品頁可以切換到「款號」，點商品就會看到哪個尺寸、哪個顏色賣最好，以及尺寸 × 顏色的賣出件數。
- **三種介面風格**：藍染（明亮）、夜航（深色、資訊密集）、市集（圓潤、適合手機），在「資料與設定」裡切換。

## 更新資料（建議：系統原始資料）

1. 從系統匯出 JMSSAL（出貨）和 JMSSBK（退貨），可以一次匯出全部期間。
2. 打開本軟體，到「資料與設定」，把 **JMSSAL.DBF 和 JMSSBK.DBF 一起**拖進去（或按「選擇檔案」一次選兩個）。不用先轉成 Excel；用 Mac 的 WPS 轉會讓中文客戶名變亂碼。
3. 原始資料有實際出貨／退貨日期（W 欄、V 欄的 DELIVDATE），月份會依實際日期計算，比依單號準。要改回依單號，在「資料與設定」→「月份依據」切換。

## 更新資料（總表）

1. 照平常的方式在 Excel 更新「原始進貨表」與「原始退貨表」。
2. 打開本軟體，到「資料與設定」，把 Excel 拖進去（或按「選擇檔案」）。
3. Excel 有開啟密碼也沒關係：匯入時會跳出輸入框，在瀏覽器內解密（支援 Excel 2007 以後的 AES 加密）。密碼不儲存、不傳送，也不會在電腦上產生沒加密的副本。
4. 第一次匯入時要設定「開啟密碼」（可直接沿用 Excel 密碼）。約 10 秒會讀取完成，資料會加密存在這台電腦上，下次打開不用再讀。

軟體只讀取這兩張工作表，而且是依**表頭名稱**找欄位，欄位順序變動也沒關係。區域、商品代碼（簡化）、賣出數、毛利等欄位會由原始欄位自動重算，不依賴 Excel 公式。前面的樞紐分析表和其他工作表一律忽略。

## 手機使用

1. 在電腦的「資料與設定」設定密碼，按「匯出資料包」，會得到 `pack.dvp`（約 5MB）。
2. 用 LINE、Email 等傳給自己，在手機上打開軟體網址，輸入密碼，按「選擇資料包檔案」。LINE 若把檔案變成 zip，直接選 zip 即可。
   - 資料包**不要**放進這個 repo：repo 是公開的，而且舊版本會永久留在歷史紀錄裡。`.gitignore` 已排除 .dvp、.zip、Excel 與 `data/`。
3. 開啟資料包後，手機的開啟密碼就是資料包的密碼。
4. 在手機瀏覽器選單點「加入主畫面」，之後就能像 App 一樣開啟。

資料包使用 AES-256 加密，沒有密碼無法讀取。

## 開啟密碼

- 存在裝置上的資料（IndexedDB）一律以 AES-256-GCM 加密，金鑰由開啟密碼經 PBKDF2（60 萬次）產生，只放在記憶體中。
- 每次打開軟體都會先顯示開鎖畫面；在「資料與設定」可以更改開啟密碼或立即鎖定。
- 電腦：匯入 Excel 時設定。手機：沿用資料包的密碼。
- 忘記密碼：密碼無法找回。在開鎖畫面按「忘記密碼？」→「清除資料，重新開始」，再重新匯入 Excel 或開啟資料包。
- 舊版存下的未加密資料，第一次開啟時會要求設定開啟密碼，加密後刪除未加密的版本。

## 在電腦上安裝成軟體

用 Chrome 或 Edge 打開網址，點網址列右側的「安裝」圖示，桌面就會出現捷徑，開啟後是獨立視窗。

## 隱私

Excel 只會在你自己的裝置上處理，不會上傳到任何伺服器。repo 裡不放任何公司資料，包括加密過的資料包。
