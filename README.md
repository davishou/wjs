# 銷售分析

用來分析「總表」Excel 的進貨與退貨資料。電腦和手機都能用，不需要安裝伺服器。

## 功能

- **今月**：依實際出貨日期看最新一天（可選其他天）：當天淨銷售、本月累計和上月同期／去年同月同期比較、本月預估，本月累計走勢圖、最近 30 天每天的淨銷售，本月各業務、本月前 10 大客戶、最近的出貨日、當天的單。資料沒有實際日期時改用月份。
- **比較**：淨銷售、淨毛利、毛利率、退貨率、銷貨、退貨、單數、客戶數、平均每單，依每年／每季／每月把所有年份排在一起，每格和去年同期或上一期比較；可以只看某個區域、業務、大類、類別、客戶、款號。另外可以自選兩段期間，依業務、區域、大類、類別、客戶、款號拆開比較。
- **應收帳款**（左側「應收帳款」區）：
  - **收款登記**：照紅單的欄位輸入每位客戶每個月的應收、退貨、補價、折率（可直接打 6%）、稅金、其他、實收和各項調整（先入、溢入、保留、不足、多入、運金），網站自動算應收淨額、檢查對不對得上（同一位客戶同月的幾行合起來算），和銷售資料不同的格子標黃；輸入客戶時顯示他前幾個月的明細；備註可以寫特殊狀況。可以匯入原本的「客戶應收帳款明細表」Excel（有密碼也可以）。
  - **應收分析**：每月應收淨額與實收、折讓率、各地區／各業務、還有不足／保留／溢入的客戶、對不上的客戶。
  - 資料和銷售資料一起用開啟密碼加密，只存在這台裝置。
- **期間選擇**：業務、客戶、商品三頁共用，可以選近 30／90 天、基準月、上個月、近 3／6／12 個月、今年累計、去年、全部或自訂月份，標「跟著期間」的圖和表會一起變，並和去年同期比。
- **業務**：每位業務的淨銷售、成長、毛利、退貨率、客戶數、單數，每月曲線、每年表；搜尋一位業務看詳細情形（每年的每月曲線、每年數字、客戶（含沒再買的）、賣最多的商品、大類與區域）。
- **樞紐分析**：可依年、年月、月份、區域、業務員、客戶、類別、商品代號、簡化代碼、顏色、單位、單號分組，並橫向展開。進貨和退貨可以一起比較（淨銷售額、退貨率），可以篩選，也可以切換「彙總／明細」，結果能匯出 CSV。
- **客戶交易**：第一筆交易、最近交易、交易至今月數、靜止月數、購買頻率（天）：有實際出貨日期時 = 第一次到最近一次相隔的天數 ÷（購買天數 − 1），同一天的單只算一次；沒有日期的舊總表沿用 Excel AK～AP 欄的算法。
- **商品銷售與滯銷**：可切換商品代號或簡化代碼，顯示第一筆售出、最近售出、已賣月數、滯銷／停售月數，算法和 Excel 的 AT～AX、BM～BR 欄相同。
- **提醒**：每一項提醒下面有 2～3 點建議可以怎麼做，按「看數據」跳到那個提醒背後的數據表。只列出要處理的事：重點提醒（自動找出要注意的地方）、新客戶、可能流失、衰退的大客戶、該來買還沒來的客戶、漸漸沒來的客戶、滯銷商品、退貨率最高的款號、損益兩平（填每月固定費用）、應收帳款天數（填應收帳款餘額），以及缺少哪些資料。
- **示範資料**：「資料與設定」→「看示範資料」，用一組假的公司資料看每一頁的樣子。只放在畫面上，不會存檔，也不會影響你的資料；看完按「回到我的資料」。
- **圖表報告**：給管理人員看的比較圖，一年一份並和去年同期比較：重點數字、每月淨營收、歷年比較（每年同一段期間）、TOP 10 客戶、TOP 15 商品、區域佔比、各品項佔比、男女童百貨比例、商品毛利貢獻排行。每張圖有一句重點和數字表。可以用「簡報模式」開會投影（一張圖一頁，方向鍵換頁），或「列印／存成 PDF」寄給主管（A4 橫向，一張圖一頁）。
- **商品類別代碼表**：在「資料與設定」匯入代碼表（商品類別(代碼)、商品類別、大類），就會顯示類別名稱和男／女／童／配件大類。只加密存在你的裝置，資料包會一起帶到手機，不會放進 repo。
- **尺寸與顏色**：商品頁可以切換到「款號」，點商品就會看到哪個尺寸、哪個顏色賣最好，以及尺寸 × 顏色的賣出件數。
- **三種介面風格**：藍染（明亮）、夜航（深色、資訊密集）、市集（圓潤、適合手機），在「資料與設定」裡切換。圖用繽紛的分類色，同一個區域、大類、業務在每張圖都是同一個顏色。
- **儀表板（試看）**：三個版面讓你挑：A 經營概況、B 每日監控、C 業績結構。

## 更新資料（建議：系統原始資料）

1. 從系統匯出 JMSSAL（出貨）和 JMSSBK（退貨），可以一次匯出全部期間。
2. 打開本軟體，到「資料與設定」，把 **JMSSAL.DBF 和 JMSSBK.DBF 一起**拖進去（或按「選擇檔案」一次選兩個）。不用先轉成 Excel；用 Mac 的 WPS 轉會讓中文客戶名變亂碼。
3. 之後只要匯出新的期間（一個月、幾天都可以），一樣丟進「更新資料」的框框（只有這一個入口）。規則和總表更新工具一樣：依**單號**比對，新的單直接加入；網站裡已經有的單改用系統的新資料，但**業務員保留原本的**；這段期間內網站有、系統沒有的單（多半是作廢）會先列出來，問你要不要刪。加入前會先讓你確認。
4. **原始檔加密備份**：匯入完成後會問你要不要把 JMSSAL、JMSSBK **原封不動**（每一欄都在，包括 RECEIVE、PAY）加密成一個備份檔（`原始資料備份_日期.dvr`），用當時的開啟密碼上鎖。存好就可以把原檔刪掉。要用時到「資料與設定」→「原始檔備份」→「還原備份」，輸入做備份當時的開啟密碼：可以直接匯入網站（不會產生沒加密的檔案），或存回原本的 DBF 檔（用完記得刪掉）。換電腦時，還原備份也能當第一次匯入，開啟密碼沿用備份的密碼。
   - 備份檔**不要**放進這個 repo（`.gitignore` 已排除 .dvr）。
5. 原始資料有實際出貨／退貨日期（W 欄、V 欄的 DELIVDATE），月份會依實際日期計算，比依單號準。要改回依單號，在「資料與設定」→「月份依據」切換。

## 更新資料（總表）

1. 照平常的方式在 Excel 更新「原始進貨表」與「原始退貨表」。
2. 打開本軟體，到「資料與設定」，把 Excel 拖進去（或按「選擇檔案」）。已經有資料時會問你：「只更新這些月份」（檔案裡有的月份換成新內容，其他月份不動）或「整份取代」。
3. Excel 有開啟密碼也沒關係：匯入時會跳出輸入框，在瀏覽器內解密（支援 Excel 2007 以後的 AES 加密）。密碼不儲存、不傳送，也不會在電腦上產生沒加密的副本。
4. 第一次匯入時要設定「開啟密碼」（可直接沿用 Excel 密碼）。約 10 秒會讀取完成，資料會加密存在這台電腦上，下次打開不用再讀。

軟體只讀取這兩張工作表，而且是依**表頭名稱**找欄位，欄位順序變動也沒關係。區域、商品代碼（簡化）、賣出數、毛利等欄位會由原始欄位自動重算，不依賴 Excel 公式。前面的樞紐分析表和其他工作表一律忽略。

## 手機使用

1. 在電腦的「資料與設定」設定密碼，按「匯出資料包」，會得到 `pack.dvp`（約 5MB）。
2. 用 LINE、Email 等傳給自己，在手機上打開軟體網址，輸入密碼，按「選擇資料包檔案」。LINE 若把檔案變成 zip，直接選 zip 即可。
   - 資料包**不要**放進這個 repo：repo 是公開的，而且舊版本會永久留在歷史紀錄裡。`.gitignore` 已排除 .dvp、.zip、Excel 與 `data/`。
3. 開啟資料包後，手機的開啟密碼就是資料包的密碼。
4. 在手機瀏覽器選單點「加入主畫面」，之後就能像 App 一樣開啟。

資料包使用 AES-256 加密，沒有密碼無法讀取。

## 開啟密碼

- 存在裝置上的資料（IndexedDB）一律以 AES-256-GCM 加密，金鑰由開啟密碼經 PBKDF2（60 萬次）產生，只放在記憶體中。
- 每次打開軟體都會先顯示開鎖畫面；在「資料與設定」可以更改開啟密碼或立即鎖定。
- 電腦：匯入 Excel 時設定。手機：沿用資料包的密碼。
- 忘記密碼：密碼無法找回。在開鎖畫面按「忘記密碼？」→「清除資料，重新開始」，再重新匯入 Excel 或開啟資料包。
- 舊版存下的未加密資料，第一次開啟時會要求設定開啟密碼，加密後刪除未加密的版本。

## 在電腦上安裝成軟體

用 Chrome 或 Edge 打開網址，點網址列右側的「安裝」圖示，桌面就會出現捷徑，開啟後是獨立視窗。

## 隱私

Excel 只會在你自己的裝置上處理，不會上傳到任何伺服器。repo 裡不放任何公司資料，包括加密過的資料包。
