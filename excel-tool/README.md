# 總表更新工具

把每月的 **JMSSAL**（進貨）和 **JMSSBK**（退貨）新資料，接到總表的「原始進貨表」「原始退貨表」下方。
用 Excel 本身來改，所以樞紐分析、Power Pivot、表格都不會被弄壞。**原本的總表不會被修改**，結果另存成新檔。

只能在有安裝 Excel 的 Windows 電腦上使用。

## 使用方法

1. 雙擊 `更新總表.cmd`。
2. 依序選擇：
   1. 總表 Excel
   2. JMSSAL（`.DBF` 或另存的 `.xlsx` 都可以；這次沒有就按「取消」）
   3. JMSSBK（同上）
3. 總表有開啟密碼的話，Excel 會跳出視窗請你輸入。
4. 等黑色視窗跑完（總表很大，開檔、重新計算、更新樞紐各要等幾分鐘）。
5. 選擇新檔名存檔，預設是 `00_總表_今天日期.xlsx`。同一個資料夾會多一份 `更新報告_日期.txt`。

## 工具會做什麼

| 項目 | 做法 |
|---|---|
| 對應欄位 | JMSSAL 的前 22 欄 → 原始進貨表 A～V；JMSSBK 的前 21 欄 → 原始退貨表 A～U（最後的 DELIVDATE 不放）。表頭不對時會停下來，避免選錯檔案。 |
| 重複 | 以**整張單號**為單位比對。整張單的每一列、每一格都一樣 → 跳過。空白和 0、文字「1」和數字 1 視為一樣。 |
| 新的單號 | 總表沒有的單號 → 新增。 |
| 單號已經有、但內容不一樣 | **改用新資料**，但**業務員保留總表原本的**。只有業務員不同的單，等於不動。筆數不同時（新資料多一列或少一列）也照新資料。報告會寫出每張單哪些欄位不同。 |
| 順序 | 進貨依出貨單號、退貨依退貨單號。有比較早的單號（例如晚到的 3 月退貨），會整張表重新排序，插回該月的位置；同一張單裡的順序不變。 |
| 公式 | 進貨 W～AE、退貨 V～AB 照第 2 列的公式往下補。 |
| 空白列 | 資料下面的空白列（表格1 多出來的列、一路到最底的 AE 公式）會清掉，表格縮到最後一筆資料。檔案變小，開啟和計算都比較快。 |
| AK、AT、BM 的 UNIQUE 清單 | 清單變長時，右邊的 AL～AP、AU～AX、BN～BR 公式跟著補到最後一列。 |
| BB～BJ 對照表 | BB（代號+客戶）、BC（商品代號）、BI（商品代碼(簡化)）整張改成和 AK、AT、BM 的清單一模一樣。其他（年份、年月、月份、區域、顏色、類別）把進貨資料新出現的值加到最下面。 |
| AR2 | 自動填成「最新資料的下一個月」，例如資料到 11409 → 填 11410。 |
| 型態 | 每一欄照總表原本的型態存：單號是文字、單位(數字)和業務員是數字。 |
| 最後 | 重新計算、更新所有樞紐分析與 Power Pivot，再另存新檔。計算模式（自動／手動）維持原本的設定。 |

## 更新完之後

把新的總表匯入[銷售分析網站](https://davishou.github.io/wjs/)（「資料與設定」→ 拖進去），網站一樣能分析。

## 給開發者

- `update-master.ps1`：主程式（PowerShell 透過 Excel 自動化）。存檔必須是 **UTF-8 含 BOM**，Windows PowerShell 5.1 才讀得懂中文。
- 測試：`powershell -NoProfile -ExecutionPolicy Bypass -File tests\excel_tool_test.ps1`。會用假資料建立和真總表同樣結構的檔案（表格、公式、UNIQUE 清單、對照表、樞紐、DBF、有密碼的總表），跑完印出「全部通過」。
